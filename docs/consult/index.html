よくある質問

新馬戦は何を見るの？

まだ過去のレースが少ないので、調教、血統、体つき、距離に合いそうか、厩舎や騎手などをいくつか合わせて見ます。

連対率って何？

1着か2着に入った割合です。たとえば10回走って、そのうち3回が1着か2着なら30%です。

血統ってどこまで大事？

距離や芝・ダート、馬場への向き不向きを考える材料の一つです。血統だけで勝つ馬を決めるものではありません。

本命と穴馬の違いは？

本命はそのレースで中心に考える馬。穴馬は評価が低く見られやすいけれど、展開や条件次第で上位に来る可能性を考える馬です。
