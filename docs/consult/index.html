競馬のこと、
AIにそのまま聞けます。

「この馬ってどんな馬？」「ハイペースならどうなる？」「この買い方どう？」みたいな文章でOK。AIが判断できないところは作り話をせず、何を見れば分かるかまで案内します。

AI回答のルール
登録済みの固定文を答えとして返しません。レース固有のデータが必要なのに取得できていない場合、馬名・確率・オッズを推測せず、「馬データ」「AI答え合わせ」「詳細分析」など確認できる機能をご案内します。

競馬ワードはAI回答の元ネタではなく、回答中の専門用語を分かりやすく確認するための補助辞典です。AIが新しく使った用語は候補台帳にも蓄積します。
